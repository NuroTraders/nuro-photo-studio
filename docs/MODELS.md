# Model policy (future phase)

No model is part of Phase 0. No model is downloaded by the app.

Before a future model is offered, document model/version, authoritative source, license for both code and weights, redistribution limits, file size, SHA-256, input/output tensor contract, preprocessing/postprocessing, verified runtime and execution-provider profiles, fallback behavior, and known quality/identity limitations. Ask before download, display storage requirements, support cancellation/removal, verify checksum, and never overwrite the original image. Do not claim a WebGPU model is interchangeable with a WASM model without validating shapes and output quality.
